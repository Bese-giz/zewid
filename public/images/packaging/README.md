# Current packaging images

Eight products use the matching bilingual label design. Abish and Korerima include 250 g, 500 g and 1 kg image files. Korerima is whole seeds removed from pods, not powder. The image map contains product names, descriptions, ingredients and size-specific filenames.

Pouch PNGs are 2508 x 2508 pixels with transparent backgrounds. High-resolution PNG and editable SVG label masters are kept in the repository's `assets/packaging-labels/` folder, outside public website photos. `labelFile` and `labelSvg` in the image map are repository source paths. Website QR codes point to https://www.zewid.com; the supplied read-back results are preserved in `docs/catalog/packaging-qr-validation.json`.

Abish and Korerima use their explicit `-250g-pouch.png` files as the default photos. The duplicate unsized pouch copies are in `photos-to-delete/`; old public aliases still resolve to the active 250 g files.

Mitin Shiro / ምጥን ሽሮ now has 500 g and 1 kg labels and pouch images. Its old unnamed Shiro artwork has been retired.
