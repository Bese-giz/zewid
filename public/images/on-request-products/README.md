# On-request product images

14 original supplier JPG photos for nine products, matched to catalog entries 25–33.

Website folder: `public/images/on-request-products/`.
Public image URL example: `/images/on-request-products/rekebot-silver.jpg`.

`image-map.json` maps each catalog ID to its primary photo, ordered gallery URLs and alt text. Use the public URLs directly. Additional views end in -2, -3 or -4.

Published names, supplied descriptions, specifications, Amharic names and photo galleries are stored in `src/data/products.ts`. The original draft copy and verification notes are retained in `docs/catalog/additional-products.draft.json` for reference. Use the public URLs in this image map for website images.

The products are published as available on request, not stocked locally. Entries 25–33 appear once each in the public catalog. Their only order action is WhatsApp; price, supplier availability and delivery are discussed before ordering. No retail prices or lead times have been assigned, and these listings cannot be added to the cart or purchased through online checkout.
