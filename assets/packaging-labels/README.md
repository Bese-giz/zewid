# Packaging label masters

Six size-specific label designs are retained for printing and editing: Abish and Korerima in 250 g, 500 g and 1 kg sizes.

- `png/`: high-resolution print exports.
- `svg/`: editable label sources.

The website uses pouch mockup photos from `public/images/packaging/`. Their image map points here for the corresponding print-label source files. Duplicate unsized label exports are in `photos-to-delete/`; the 250 g versions are the canonical masters.
